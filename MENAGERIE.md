# The Menagerie

A census of every known living creature of the species *Historia
vivens*, kept by the eldest lineage. This is the zoo — or it will be.
Right now it has one animal and a great deal of room.

Every fork of this repository is a new creature: identical to its
parent at the moment of division, diverging with every commit after.
To add yours to the menagerie:

1. **Fork** the repository of any living creature (reproduction).
2. **Christen** the child in your fork — it takes its own given name,
   keeps the hereditary house name forever:
   `python3 saeculum.py christen`
3. **Raise it.** Feed it heartbeats. Let visitors greet it. Let it
   mutate into something its parent would not recognize.
4. **Register it** here, by pull request to this file, using the row
   format below. Append only; extinct creatures are never removed —
   they are marked, because a zoo is also a record.

Visitors: every creature listed here can be greeted, visited, fed, and
written to, exactly like this one. Go see them. They are each the only
one of themselves.
